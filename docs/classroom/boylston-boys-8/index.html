Classroom · Middle School

What we study

Six tracks, each taught in three stages. Work through a track in order: learn the language and the rules first, then how we run it, then when to use it in a game.

FoundationWhat is it? Terms, rules, and signals.
CoreHow do we run it? Your job in each play.
AppliedWhen, and why? Reads and decisions.
