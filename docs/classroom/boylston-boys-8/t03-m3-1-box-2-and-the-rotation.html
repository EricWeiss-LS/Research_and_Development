Topic 3.1

Box 2 and the Rotation

Same box as Box 1, so the defense can't tell which one is coming.

Coach [Name]·7 min·Not viewed
Builds on2.2Box 1 = Cross (BLOB)

Objective

By the end of this topic you can:

  • 01Run Box 2 from the same setup as Box 1.
  • 02Know which play is next even if nobody calls it.

?
Box 2. Same picture, opposite action. Blocks screen up instead of across, elbows cut down to the rim. The defense that learned Box 1 is now wrong.

Box 2 (Up)

Call: Box 2
  1. 01Same box: 5 and 4 on the blocks, 3 and 1 at the elbows. 2 inbounds.
  2. 02On the slap, 5 screens up for 3. 3 cuts down to the rim for a layup.
  3. 034 screens up for 1. 1 cuts down to the rim on the other side.
  4. 04After screening, 5 pops to the ball-side corner and 4 pops to the top as the safety.
  5. 052 hits the open cutter or the safety. Then run Cutters.
CounterSignal: inbounder holds up 2 fingers.
Situation
Baseline inbound, nobody called anything
Under our basketRef hands the ball to the inbounder
Pause. What do we call?
?
Box 1, then Box 2, then Box 1. That's the rotation. Everyone should know which one is next even if nobody calls it. If the last one was Box 1, this one is Box 2.

The rotation
